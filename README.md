# Denver-projekat
Razvio sam WPF aplikaciju u C# za upravljanje korisnicima i košarkašima. Implementirao sam funkcionalnosti kao što su autentifikacija korisnika, dodavanje, uređivanje i brisanje podataka, kao i serijalizacija podataka u XML format. Dizajnirao sam prilagođeni korisnički interfejs za poboljšanje upotrebljivosti i efikasno upravljanje podacima.
